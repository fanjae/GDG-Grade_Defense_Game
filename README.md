## Grade Defense Game (README 진행중)

<img width="620" height="420" alt="Image" src="https://github.com/user-attachments/assets/e0974b4f-c51a-4f93-a7c5-113b2c5b30a9" />

> Grade Defense Game은 학점을 테마로 한 웨이브 기반 3D 타워 디펜스 게임입니다.
> 플레이어는 제한된 자원으로 타워(학생)를 배치하여 몰려오는 적들로부터 학점을 지켜야 합니다.

### 게임 기능 
- 웨이브 기반 스테이지 진행
- 총 9종의 특성별 타워 구현 
- 총 7종의 몬스터 구현
- 슬로우 및 지속 피해, 스턴 등 상태이상 시스템
- 적 처치 시 코인 획득 시스템
- 라이프 기반 게임 오버

## 조작 방법

| 키 | 기능 |
|:---:|---|
| ↑ ↓ ← → | 메뉴 이동 |
| Enter 또는 마우스 왼쪽 클릭 | 메뉴 선택 |
| 마우스 왼쪽 클릭 | 타워 설치 |
